# 梗王幸存者

电脑浏览器单人割草肉鸽游戏，使用 Phaser、TypeScript 和 Vite 开发。

## 在线试玩

[点击开始游戏](https://Stewie985211.github.io/gengking-survivors/)

WASD / 方向键移动，空格闪避，自动瞄准攻击，Esc 暂停；升级时点击卡片或按 1 / 2 / 3。

## 最新版内容

- 每局七关：前六关各有 120 秒普通波次和随机单 Boss 战；第七关八位 Boss 同时登场，全部击败才能通关。
- 第七关地图为 3600×3000，是普通地图面积的 2.25 倍。
- 八位 Boss、八种基础武器、八种被动及冰汽水风暴融合武器，包含人物专属配音。
- 前六关升级最短间隔依次为 20 / 20 / 26 / 32 / 38 / 44 秒普通战斗时间；Boss 战暂停升级。
- 第五、六关不提供回血升级；人物精英怪有 30% 概率掉落恢复 25 生命的血包。
- 设置、解锁与最近 20 局战绩保存在当前浏览器，同其他域名及本地版的存档分别保存。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm test
npm run build
npm start
```

构建后打开 http://127.0.0.1:4173/ 。Windows 也可在构建完成后双击“启动游戏.cmd”。开发模式使用 `npm run dev`。

## 自动部署

推送到 main 后，GitHub Actions 安装固定依赖、运行 43 项测试、进行类型检查并构建，成功后发布 dist 到 GitHub Pages。

源码位于 src，测试位于 tests，游戏必需素材位于 assets。仓库不包含开发缓存、内部笔记、素材重复归档或账号配置。

本项目含第三方人物图片、梗图与音频素材；这些素材的权利属于各自权利人，本仓库不对其授予额外使用许可。
